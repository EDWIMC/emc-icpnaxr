# FUTURE VISION XR 3D assets

Seven browser-ready GLB models are loaded by `src/main.js`: robot, cybertruck, Mars, Moon, satellite / Mars Space Station, Falcon 9 Heavy, and SpaceX Big Falcon Rocket. The `manifest.json` file records mesh counts and approximate file sizes.

All assets were supplied in the user's `Objetos 3D.rar` archive. The lunar sphere mesh was generated from the textures packed into the supplied `vid_mmoon.blend` file because Three.js does not load Blender project files directly. Check original asset license and attribution terms before public or commercial redistribution.
